What is a string?

A string is text. In Python, text is surrounded by quotation marks.

first_name = "Daniel"
Notice: first_name is the variable name and "Daniel" is the string value.
2

See it in action

Python can store a string in a variable and print it later.

greeting = "Hello"
name = "Daniel"

print(greeting)
print(name)

The output would be:

Hello
Daniel
